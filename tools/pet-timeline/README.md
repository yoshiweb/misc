# うちの子（犬猫）成長カレンダー

犬・猫の生年月日と犬種から現在の成長段階を判定し、その段階で必要になるグッズとフードの給与量を算出するブラウザ向けツールです。

ディレクトリ名（`tools/pet-timeline/`）とローカルストレージのキー（`pet-timeline.v1`）は、サービス名を変更したあとも旧名のままです。URLを変えると公開済みのリンク・SNSのキャッシュ・検索インデックスが切れ、キーを変えると既存利用者の保存データが消えるためです。

## 概要

- 種別（犬/猫）・生年月日・品種・体重を入力すると、リアルタイムに結果が更新されます。
- 品種を選ぶと体格の区分が自動で決まり、成犬・成猫期に入る月齢が切り替わります。
- 成長段階を縦のタイムラインで示し、現在地を「いまここ」として強調します。過去の段階と先の段階を同時に見られるため、次に必要になるものを先回りして準備できます。
- 現在の段階に該当するグッズを [assets/affiliate.js](../../assets/affiliate.js) 経由で提案します。

## 主な機能

- **成長段階の判定**: 迎える準備 / 社会化期 / 成長期 / 成長後期 / 成犬・成猫期 / シニア期 の6段階。境界は体格の区分ごとに変わります（大型犬は成犬になるのが遅くシニア期に入るのが早い、大型の猫は成熟に3年かかる、など）。
- **品種からの体格判定**: 主要な犬種・猫種を区分に対応づけて収録。品種を選ぶと区分が自動で入り、読み取り専用になるのでどう判定されたかが見えます。一覧にない場合は「わからない・ミックス」または「その他」を選ぶと、区分を直接指定できます。
- **先の段階までの期間**: 「いまここ」より先の段階には、そこに入るまでの期間を「約4ヶ月後」のように表示します。月齢の範囲だけでは、あと何ヶ月で準備が必要になるのかを読み取りにくいためです。2ヶ月以内に迫っている段階は「もうすぐ準備（約1ヶ月後）」と文言と色を変えて目立たせます。2年以上先は「約9年9ヶ月後」のように年へ繰り上げます。
- **人間換算年齢**: 現在の年齢と各段階の期間を人間の年齢に換算して併記します。犬は区分によって老化の速さが異なるため、加算年数を変えています。
- **フードの給与量算出**: 安静時エネルギー要求量（RER = 70 × 体重<sup>0.75</sup>）に成長段階と避妊去勢の有無に応じた係数を掛けて必要エネルギー（DER）を求め、フードの熱量から1日の給与量をグラム単位で算出します。
- **体重の自動推定**: 月齢から現在の体重を概算して初期値を埋めます。実測値を入力するとそちらが優先されます。
- **段階ごとの注意事項**: ワクチン、避妊去勢、健康診断、狂犬病予防法に基づく登録義務など、商品ではない情報を各段階に表示します。
- **入力の絞り込み**: 2択の項目（種別・避妊去勢）はワンクリックで選べるセグメントにしています。避妊・去勢は成犬・成猫期の給与量にしか影響しないため、それ以外の段階では非活性にして理由を示します。
- **設定は効果の見える場所に**: フードの熱量は給与量セクション、フード1袋のサイズは購入済みのフードカード内に置き、値を変えるとその場の数値が動くようにしています。
- **グッズのチェック**: 「いま必要なグッズ」の各カードに「購入済み」「不要」のチェック欄があります。どちらかが付いたものは色を落として一覧の末尾へ回るため、まだ手つかずのものだけが上に残ります。見出しの下には未チェックの件数を表示します。
- **消耗品の補充リマインド**: 商品カードで「購入済み」にチェックを付けると、そのカード内に購入日・補充サイクル・次回の補充目安日を表示します。購入済みの商品だけで補充状況を管理できます。
- **次の段階の準備**: 「いま必要なグッズ」のあとに、次の成長段階で新たに必要になるグッズを表示します。今の段階と重複する商品は除き、先回りして準備できます。
- **SNSへの共有**: 判定結果を X / LINE / Facebook / はてなブックマークへ共有できます。共有本文はページ内に表示され、押す前に内容を確認できます。

## グッズのチェック

買い物の途中で中断しても、どこまで済んだかが分かるようにするための機能です。

- **2種類のチェック**: 「購入済み」と「不要」を別々に持ちます。どちらも一覧の優先度を下げるという意味では同じですが、買ったのか要らないのかは利用者にとって別の情報のため分けています。
- **色を落として末尾へ**: チェックが付いたカードは不透明度を下げ、一覧の末尾へ回します。消さずに残しているのは、間違えて付けたときに戻せるようにするためです。ポインタを乗せると元の濃さに戻り、チェックを外しやすくしています。
- **並び順**: 未チェックのものが先、チェック済みが後。同じ状態のもの同士は商品データの優先度順のままです（安定ソート）。
- **保存**: 商品IDをキーにローカルストレージへ保存します。成長段階が進んでも記録は残るため、同じグッズが次の段階にも出てくる場合はチェックが引き継がれます。

「いま必要なグッズ」と「もうすぐ必要になるグッズ」の両方でチェックを使えます。「購入済み」にした消耗品には、同じ商品カード内で補充リマインドを設定できます。

## 消耗品の補充リマインド

再訪の主な動機になる機能です。商品カードで「購入済み」にした消耗品だけに購入日とサイクルの入力欄が現れ、購入日から次回の補充時期を算出します。

- **フードは実際の消費ペースで算出**: 1日の給与量と袋のサイズから消費日数を計算するため、既定値ではなく実態に沿った日数になります。たとえば成長期の大型犬で3kgの袋を使っている場合、8日で使い切る計算になります。
- **それ以外は既定サイクル**: ペットシーツ30日、猫砂30日、消臭剤60日、歯磨きペースト90日などを初期値とし、実際の消費ペースに合わせて利用者が編集できます。編集した値は保存され、以降はそちらが優先されます。
- **操作場所**: 補充情報は独立した一覧ではなく、該当する商品カードの中に表示します。商品と補充情報を一緒に確認できます。
- **状態表示**: 目安超過（赤）/ 5日以内（黄）/ 余裕あり（緑）/ 未記録（灰）でバッジの色が変わります。

## SNSへの共有

結果エリアの末尾に共有セクションを置いています。共有は [../../assets/share.js](../../assets/share.js) が担当し、このツールは共有本文の組み立てだけを行います。

- **共有先**: X / LINE / Facebook / はてなブックマーク。`navigator.share` が使える環境では、先頭にOS標準の共有シートを開くボタンが出ます。加えて、本文とURLをまとめてクリップボードへコピーできます。
- **共有本文**: `🐶 うちの子（トイ・プードル・2歳3ヶ月）はいま「成犬・成猫期」。人間でいうと約25歳です。` のように、品種・年齢・成長段階・人間換算年齢で組み立てます。品種が「わからない・ミックス」「その他」の場合は体格の区分名（小型犬など）を使います。
- **共有前の確認**: 本文には品種と年齢が入るため、ボタンの上に本文をそのまま表示し、何が流れるのかを見てから押せるようにしています。共有されるのは本文とツールのURLだけで、生年月日・体重・消耗品の記録は含まれません。
- **ハッシュタグ**: Xのみ `#うちの子成長カレンダー` を専用パラメータで付与します。本文に混ぜていないのは、他の共有先で重複して見えるのを避けるためです。括弧を含むとそこでタグが切れるため、サービス名から `（犬猫）` を外した表記にしています。
- **共有されるURL**: `<link rel="canonical">` の値を使います。localhost や `file://` で開いた状態から共有しても、公開URLが流れます。
- **OGP**: 共有されたリンクがSNS上でタイトル・説明・画像つきで表示されるよう、`og:*` と `twitter:card` を `head` に置いています。Facebook は本文を受け取らず、表示内容がOGPに依存するため、この設定が前提になります。

なお、canonical と OGP のURLは共有先の環境で解決される必要があるため、リポジトリ内で唯一、絶対URLで記述しています。

### OGP画像

[../../assets/images/ogp/pet-timeline.jpg](../../assets/images/ogp/pet-timeline.jpg) を 1200×630px で配置し、`twitter:card` は `summary_large_image`（横長カード）にしています。

- **形式**: 水彩調のイラストのため JPEG（品質88・プログレッシブ、約140KB）。クローラの取得が速いよう軽量に保ちます。WebP はFacebookのクローラで安定しないため使いません。
- **構図**: 一部のクライアントは中央を1:1にトリミングするため、主役の子犬と子猫を中央寄りに配置しています。生成時に文字を入れていないのは、タイトルと説明をカード側が表示するためと、生成AIの日本語が崩れるためです。
- **比率合わせ**: 元画像は16:9だったため、作画を切り落とさないよう用紙の余白と同じ色（`#FDFAF1`）を左右に足して1.91:1にしてから縮小しています。
- **差し替え時**: `og:image` は絶対URLで書いているため、パスを変える場合は `head` の記述も合わせて更新してください。SNS側にキャッシュが残るため、反映されない場合は各社のデバッガでキャッシュを更新します。

## データの保存について

入力内容・消耗品の購入日・グッズのチェックはブラウザのローカルストレージ（キー `pet-timeline.v1` — 名称変更前のまま）に保存され、次回アクセス時に復元されます。サーバーには送信されません。ペット1匹分を想定した単一プロファイル構成です。

保存データが壊れている場合や、プライベートモードなどで書き込めない場合は、警告をコンソールに出したうえで初期状態のまま動作を継続します。

## 成長段階の境界

| 区分 | 成犬・成猫期に入る月齢 | シニア期に入る月齢 |
| --- | --- | --- |
| 超小型犬 | 10ヶ月 | 10歳 |
| 小型犬 | 12ヶ月 | 10歳 |
| 中型犬 | 12ヶ月 | 8歳 |
| 大型犬 | 18ヶ月 | 7歳 |
| 小柄な猫 | 12ヶ月 | 11歳 |
| 標準的な猫 | 12ヶ月 | 11歳 |
| 大型の猫 | **36ヶ月** | 11歳 |

猫は体格差こそ犬ほどではありませんが、メインクーンやノルウェージャン・フォレスト・キャットなどの大型種は成熟が遅く、体格が固まるまで3年前後かかります。一律12ヶ月で扱うと、まだ成長期の大型種に成猫の係数を当ててしまい、給与量を3〜4割少なく見積もることになるため区分を分けています。シニア期に入る月齢は品種差より個体差が大きいため、猫は一律です。

## 給与量の算出係数

| 成長段階 | 犬 | 猫 |
| --- | --- | --- |
| 生後4ヶ月未満 | 3.0 | 2.5 |
| 4ヶ月〜成犬・成猫期まで | 2.0 | 2.0 |
| 成犬・成猫期（避妊去勢 未実施 / 実施済み） | 1.8 / 1.6 | 1.4 / 1.2 |
| シニア期 | 1.4 | 1.1 |

## 人間換算年齢

2歳までは成長が速いため次のアンカーで補間し、それ以降は区分ごとの加算年数で直線的に増やします。

| 月齢 | 1 | 3 | 6 | 12 | 24 |
| --- | --- | --- | --- | --- | --- |
| 人間年齢 | 1 | 5 | 9 | 15 | 24 |

| 区分 | 2歳以降の加算年数/年 |
| --- | --- |
| 超小型犬 / 小型犬 | 4 |
| 中型犬 | 5 |
| 大型犬 | 7 |
| 猫（全区分） | 4 |

この係数でシニア期に入る月齢を換算すると、大型犬7歳 ≒ 59歳 / 小型犬10歳 ≒ 56歳 / 猫11歳 ≒ 60歳となり、いずれも人間の50代後半に揃います。区分ごとにシニア移行を変えている既存の設計と噛み合っており、換算値の妥当性の裏付けになります。

一般に用いられている目安であり、獣医学的な定義ではありません。

## 広告表記について

- **PR表記**: 景品表示法（ステマ規制）に対応するため、商品リンクの直前に `[PR] アフィリエイト広告を利用しています` を表示します。
- **アソシエイト表記**: Amazonアソシエイト・プログラム運営規約で義務付けられている表記と、楽天アフィリエイトへの参加をページ下部に常時表示します。
- **ストアの併記**: 各商品に Amazon と楽天の両方へのリンクを表示します。
- **価格の非表示**: PA-API を利用していないため、規約上価格を掲載できません。商品データにも価格を持たせていません。

## 商品イラスト

商品カードにイラストを表示します。画像は [../../assets/images/pet/](../../assets/images/pet) に商品IDと同じ名前の WebP で置き、商品データの `image` からツールの index.html を基点にした相対パスで参照します。

- 元画像は長辺480pxの WebP（品質80）に変換して配置しています。カード内での表示は最大128×80pxのため、Retina環境でも十分な解像度です。
- 全34品目にイラストが設定されています。未設定の商品があった場合は、同じサイズの枠だけを表示してカードの左端を揃えます。この枠は、そのカテゴリに1つでもイラストがある場合にのみ出るため、イラストを使わない他のツールには影響しません。

### 犬と猫で絵柄を分ける

ケージ・食器・給水器・ベッドのように犬猫の両方で使う品目は、`image` をオブジェクトで持ち、種別ごとに絵柄を切り替えます。

```js
image: {
    dog: '../../assets/images/pet/crate-dog.webp',
    cat: '../../assets/images/pet/crate-cat.webp'
},
```

ツール側は選択中の種別を `imageVariant` として渡します。該当するバリアントがない場合は最初の1つが使われるため、片方だけ用意した状態でも壊れません。

### イラストの追加手順

1. 長辺480pxの WebP に変換し、`assets/images/pet/<商品ID>.webp` として保存する（犬猫で分ける場合は `<商品ID>-dog.webp` / `<商品ID>-cat.webp`）
2. [../../data/products/pet.js](../../data/products/pet.js) の該当商品に `image` を追加する
3. [../../assets/affiliate.js](../../assets/affiliate.js) 冒頭の手順に従い、script タグのバージョンを上げる

## 免責について

成長段階の区切りとフードの給与量は一般的な目安であり、獣医学上の助言ではありません。ワクチンの接種スケジュール、避妊・去勢の適齢期、健康診断の頻度、療法食の必要性については獣医師への相談を促す注記をページ内に常時表示しています。医薬品・医薬部外品は商品データに含めていません。

## 技術メモ

- Tailwind CSS と lucide を CDN から読み込む、ビルド不要の単一HTML構成です。
- 商品データは `Affiliate.registerProducts()` で登録します。JSON ではなく JS ファイルにしているのは、`file://` で直接開いた際に `fetch` が CORS で失敗するのを避けるためです。
- 月齢は「同じ日付を過ぎたら1ヶ月」として数えており、暦の月の長さの差を吸収しています。
- 商品カードは DOM API で構築しており、`innerHTML` に商品データを流し込んでいません。
- 2択のセグメントは `sr-only` のネイティブラジオに `.segment` を添える構成です。矢印キー操作と `fieldset`/`legend` によるグループの読み上げがそのまま効きます。CDN版の Tailwind では `@apply` が使えないため、`.segment` はプレーンCSSで定義しています。
- 結果エリアは `update()` のたびに作り直されるため、その中に置く入力（フードの熱量・袋のサイズ・購入日・サイクル）は DOM ではなく `store` を値の持ち主とし、`change` のみで拾います。`input` で拾うと1文字ごとの再描画でフォーカスが外れます。
- 品種の一覧は種別によって総入れ替えになるため、復元時は種別を先に戻してからセレクトを組み立てます。
- 共有ボタンはいずれもGETのシェアURLを開くだけで、各SNSのSDKやトラッキング用スクリプトは読み込んでいません。クリップボードへのコピーは `navigator.clipboard` が使えない環境（`file://` など）では `textarea` を使った方法へ退避します。

## 商品データの追加・変更

[../../data/products/pet.js](../../data/products/pet.js) を編集します。各商品は対象種別（`species`）と該当する成長段階（`stages`）を持ちます。価格は規約上掲載できないため、**商品データに価格を持たせないでください**。
