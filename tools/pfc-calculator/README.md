# PFCカロリー計算機

体格と目標から1日の目標カロリーとPFC（タンパク質・脂質・炭水化物）バランスを算出し、タンパク質の不足分から補給に必要な量とアイテムを提案するブラウザ向けツールです。

## 概要

- 性別・年齢・身長・体重・目標（減量/維持/増量）・運動頻度を入力すると、リアルタイムに結果が更新されます。
- 「食事から摂れているタンパク質の目安」を差し引いた不足分から、1日あたりの杯数と1ヶ月に必要な粉末量を算出します。
- 算出結果に応じた商品を [assets/affiliate.js](../../assets/affiliate.js) 経由で提案します。

## 主な機能

- **カロリー算出**: Mifflin-St Jeor 式で基礎代謝量を求め、活動係数を掛けて消費カロリーを算出。目標に応じて減量は −20%、増量は +10% を適用します。
- **PFC算出**: タンパク質は体重比（減量 2.0 / 維持 1.6 / 増量 1.8 g/kg）、脂質は総カロリー比（減量 22% / その他 25%）、炭水化物は残りのカロリーから逆算します。
- **構成比の可視化**: PFCのカロリー比率を積み上げバーと内訳カードで表示します。
- **補給量の算出**: 不足分を1杯あたり粉末30g（タンパク質約20g）換算で杯数・月間必要量に変換します。
- **目標に応じた商品の絞り込み**: 目標に合致する商品のみを表示し、タンパク質が足りている場合はプロテイン本体と炭水化物の提案を出しません。

## 安全上のガード

計算結果が不健全な値にならないよう、以下の制御を入れています。

- **基礎代謝量のクランプ**: 減量時に目標カロリーが基礎代謝量を下回る場合、基礎代謝量に丸めたうえで警告を表示します。
- **タンパク質の下限**: 炭水化物のカロリーが確保できない場合はタンパク質を圧縮しますが、1.2 g/kg を下限とします。それでも収まらない極端な入力では警告を表示します。
- **不足0の明示**: 食事で目標量を満たしている場合は「補給は必要ない」と明示します。

## 免責について

本ツールの算出値は一般的な推定式による目安であり、医療上・栄養学上の助言ではありません。持病・服薬・妊娠授乳中・未成年の場合は専門家への相談を促す注記をページ内に常時表示しています。また、紹介するアイテムは食品・雑貨であり、疾病の治療や予防を目的とするものではないことを明記しています。

## 技術メモ

- Tailwind CSS と lucide を CDN から読み込む、ビルド不要の単一HTML構成です。
- 商品データは `Affiliate.registerProducts()` で登録します。JSON ではなく JS ファイルにしているのは、`file://` で直接開いた際に `fetch` が CORS で失敗するのを避けるためです。
- 商品カードは DOM API で構築しており、`innerHTML` に商品データを流し込んでいません。
- 商品データの `asin` は未設定（`null`）でも、`searchKeyword` による検索結果リンクとして機能します。ASINを設定すると商品ページへの直リンクに切り替わります。

## 商品データの追加・変更

[../../data/products/supplements.js](../../data/products/supplements.js) を編集します。価格は規約上掲載できないため、**商品データに価格を持たせないでください**。詳細は [../../assets/affiliate.js](../../assets/affiliate.js) 冒頭のコメントを参照してください。
