# サムネイルジェネレーター Thumbnail Generator

ブログ用のアイキャッチ画像や SNS 用サムネイルを、ブラウザ上で簡単に作成できるツールです。テキスト・配色・レイアウト・背景画像・挿絵を組み合わせて、16:9 のプレビューをその場で確認しながら PNG としてダウンロードできます。

## 概要

このツールは、次のような用途で使えます。

- ブログのアイキャッチ画像作成
- YouTube / SNS 用サムネイル作成
- 記事や投稿の見出しを目立たせるビジュアル作成
- テンプレートを切り替えながら、短時間で複数案を作る

## 主な機能

- テキスト編集
  - メインタイトル
  - サブタイトル
  - カテゴリー
  - 日付・タグ
  - 著者名
- デザイン調整
  - 配色プリセットの切り替え
  - カスタムカラー指定
  - フォント切り替え
  - 左右レイアウトの反転
- 背景・装飾
  - ソリッド背景 / カスタム背景画像
  - 挿絵のプリセット切り替え
  - カスタム画像アップロード
  - 著者アバターの表示・カスタム化
- テンプレート
  - ミニマル
  - 左右分割
  - バッジ装飾
  - ソリッドスラッシュ
  - モダンカード
- 出力
  - リアルタイムプレビュー
  - ランダム生成
  - PNG ダウンロード

## 使い方

1. ブラウザで [index.html](index.html) を開きます。
2. 「テキスト入力」タブでタイトルや説明文を入力します。
3. 「デザイン調整」タブで配色やフォント、レイアウトを調整します。
4. 「背景・挿絵」タブで背景画像や挿絵を追加します。
5. 右側のプレビューで内容を確認し、「超美麗ダウンロード (PNG)」を押して保存します。

## 開発・実行について

- 追加のビルド手順は不要です。
- 静的な HTML / CSS / JavaScript で構成されています。
- ローカルで確認する場合は、シンプルなローカルサーバーでもブラウザ直接開きでも動作します。

## 備考

- 画面上の一部は Google Fonts、Tailwind CSS、Font Awesome を利用しています。
- 初回読み込み時はネットワーク接続が必要な場合があります。
- 生成内容はブラウザ上で即時反映されるため、試しながら調整しやすいです。
