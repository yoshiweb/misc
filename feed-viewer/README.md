# RSS Feed Viewer

このプロジェクトは、ユーザーが指定したRSSフィードのURLを読み込み、ページ上にフィードのタイトルと記事一覧を表示するブラウザ向けツールです。

## 概要
- ユーザーが RSS フィードの URL を入力して追加できます。
- フィードの取得には無料のサードパーティ RSS→JSON API（rss2json）を利用しています。
- 取得したフィードはカード状のカラムに整形して表示し、各記事はリンクで開けます。
- 追加したフィードはローカルストレージに保存され、ページ再読み込み後も復元されます。

## 主な機能
- **URL の追加・削除**: フォームによる追加（Enter送信対応）およびカード単位での削除。
- **ドラッグ＆ドロップによる並び替え**: カードのタイトルバーをドラッグして、直感的にフィードの順番をカスタマイズ可能（並び順もローカルストレージに永続化されます）。
- **折りたたみ表示**: タイトルバーをクリックすることで、記事一覧を折りたたむことが可能。
- **堅牢なセキュリティ (XSS対策)**: フィードのデータを安全にDOMに構築し、悪意あるスクリプトの混入（クロスサイトスクリプティング）を完全に防止します。
- **エラーハンドリング**: 無効なURLやネットワークエラー時は、トースト通知としてエラーを画面右下に視覚的にフィードバックします。
- **高速な並列ロード**: 起動時に複数のフィードを並列で取得するため、ロード時間が大幅に短縮され、順序の整合性も保証されます。
- **プレミアムなダークモードUI**: グラスモーフィズム調の入力フォーム、滑らかなホバーアニメーションやドラッグエフェクト、Google Fonts（`Outfit`）による美しいタイポグラフィを採用しています。

## 使い方
1. ブラウザで [index.html](index.html) を開きます。
2. テキストボックスに RSS フィードの URL を入力して `Add Feed` をクリックするか、Enterキーを押します。
3. フィードが追加され、各記事の一覧が表示されます。記事タイトルをクリックすると元のサイトを新しいタブで開きます。

## ファイル構成
- [index.html](index.html) — UI（入力フォーム、フィード表示領域、トースト通知コンテナ）
- [app.js](app.js) — フィード取得・表示・ローカルストレージ管理・レイアウト調整・ドラッグ＆ドロップ制御のロジック
- [styles.css](styles.css) — 表示用のプレミアムダークテーマスタイル
- [README.md](README.md) — このファイル

## 技術メモ
- フィード取得: `https://api.rss2json.com/v1/api.json?rss_url=...` を使用
- レイアウト: CSS Grid を使い、各アイテムの高さに合わせて `grid-row-end` を動的に設定しています。不要なリフロー（Layout Thrashing）を避けるため、レイアウト計測結果のキャッシュ（`cachedRowHeight`, `cachedRowGap`）を行っています。

## 注意事項
- 外部の RSS→JSON サービスに依存しているため、そのサービスのレート制限や可用性に影響を受けます。
- プライバシー: フィード URL はブラウザのローカルストレージに保存されますが、フィードの取得自体は外部 API 経由で行われます。
